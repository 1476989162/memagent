# 参数自学习闭环：让记忆系统自己学会"遗忘多快才对"

> memagent v0.3.0 设计哲学 · 2026-08-21

## 一个所有记忆系统都回避的问题

给 AI Agent 做记忆，绕不开一个参数：**遗忘时间常数 τ**——一条记忆过多久衰减到 37%。

现有方案（MemGPT/Letta、Mem0、Zep）的处理方式出奇一致：**拍一个值，写死在配置里**。τ=7 天，或者干脆不衰减。

但人脑不是这么工作的：

- 你记「自己的名字」几乎永不遗忘（技能类，τ 极长）
- 你记「上周三午饭吃了什么」三天就没了（情景类，τ 极短）
- **每个人不一样**：创伤经历者的情景记忆 τ 可以是常人的数倍
- **每个领域不一样**：棋手对棋局的记忆 τ 远长于他对陌生电话号码的 τ

写死的 τ 意味着：要么重要记忆被过早遗忘，要么垃圾记忆永远占着检索位。**没有任何一个固定值对所有用户、所有领域同时正确。**

## 核心思路：把 τ 从配置变成观测

memagent 的做法：不猜 τ，**从系统自己的运行数据里反推它**。

### 观测层：每条记忆都在被偷偷测量

每次对话后，系统给所有记忆采样一次当前强度：

```
history.append([时间戳, 实测强度, 最后访问, 检索次数, 重要性])
```

跑一段时间后，每条记忆都有一条真实的衰减轨迹。这就是原始数据。

### 反推层：干净段反推 + 唤醒偏差代理

**干净段反推**：找一条「写入后再也没被碰过」的记忆（没有检索、没有回放干扰），它的强度轨迹就是纯遗忘曲线。取两个采样点：

```
s(t₂) = s(t₁) · exp(−(t₂−t₁)/τ)
→ τ = −(t₂−t₁) / ln(s(t₂)/s(t₁))
```

一次反推噪声很大，所以用 EMA 平滑 + 置信度门控：样本太少不动、偏差太小不动（<0.5% 的修正不值得引入抖动）。

**唤醒偏差代理**：有些类型很难等到干净段（比如高频使用的语义记忆）。第二路观测来自 Cold 记忆唤醒：一条被压缩进冷层的记忆被唤醒时，实测强度跳升如果**深于该类型的预期跳升**，说明真实衰减比模型信念快 → τ 下调。两路互补，单一类型也能校准。

### 防御性设计：三个门控

自学习系统最大的风险是被脏数据带偏。三道闸：

1. **最少样本**：每类型至少 3 个干净衰减段才更新
2. **最小偏差**：估计值与当前值差 <0.5% 不更新（避免数值噪声驱动漂移）
3. **硬边界钳制**：学习结果限制在 [1 秒, 10 年]，极端估计直接丢弃

## 第二个闭环：可塑性也是学出来的

回忆会改写记忆（再巩固），改多狠由可塑性因子控制。这个因子同样不该写死：

- 技能类记忆（「怎么骑自行车」）回忆时高度稳定 → drift 因子 ≈ 0.15
- 情景记忆（「上周的约会」）每次回忆都被当下情境染色 → drift 因子 ≈ 2.5

memagent 从**修订日志**里实测：每次再巩固实际改了多少，与配置预期比，偏差稳定就用中位数聚合更新（中位数抗离群——一次情绪化的剧烈回忆不会带偏估计）。同样有门控：观测不足不动、因子偏差 <1% 不动。

## 联合估计：两个未知数互相加速

τ 和可塑性不是独立的——唤醒跳升幅度同时编码两者。memagent 用一个耦合公式拆开：

```
dev      = base(τ真实) · (1 + g·(p实测 − 1))
expected = base(τ模型) · (1 + g·(p信念 − 1))
```

随着可塑性信念收敛，dev/expected 比值中的可塑性成分逐年消融，剩下的就是纯 τ 信号。两个学习器互为对方的加速器。

## 为什么这件事值得做成产品

**这是基础设施级的差异化。** 所有竞品的记忆参数都是作者拍的；memagent 的参数是每个部署自己长出来的。这意味着：

1. **零调参上手**：接入方不需要理解 τ 是什么，系统自己收敛到该用户的真实值
2. **数据飞轮**：越用越准，且每个部署的参数是私有资产（迁移成本天然存在）
3. **可验证**：`fit_report()` 直接报告「你的 τ 配置 vs 实测」贴合度——参数质量从信仰变成指标

## 工程上的克制

整个学习器**零新依赖**：EMA 是一行指数加权，置信度门控是一个 if，中位数在 `statistics` 标准库里。没有引入任何 ML 框架——因为问题本身是个一维参数估计，杀鸡用牛刀只会引入部署负担。

这也是 memagent 的一贯原则：**认知科学给结构，统计学习给参数，工程克制给可靠性。**
