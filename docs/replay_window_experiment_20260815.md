# 回放窗口语义研究：1 秒 vs 最近 N 轮（2026-08-15）

**结论：默认窗口（1 秒）只让本轮新沉淀的规则被回放，旧教训沉淀后永不再次激活——这是「轮 123 沉淀 .DataTable 教训、轮 126 又复犯同一错」的机制温床。改为「最近 N 轮沉淀的规则周期性再激活」（`--replay-rounds N`）后，每轮回放量从 3 条 → 30 条，旧教训被持续强化，均分未恶化。默认采用 `--replay-rounds 10`。**

## 背景：1 秒窗口的语义

`agent.sleep()` 的回放候选 = `now - m.last_access <= replay_window_seconds`。
生产环境 `TIME_SCALE = 1/86400` → `replay_window_seconds = 24h × TIME_SCALE = 1.0 真实秒`。

含义：**只有 last_access 在最近 1 秒内的记忆能进回放窗口**。coder 每轮生成后立即 sleep，本轮新沉淀规则（last_access=now）恰好命中 → 被回放；但**上一轮、上上轮沉淀的规则（几分钟前）已经出窗，永不回放**。

实测记忆库：1262 条 skill 中 1217 条 last_access > 1 小时，从未被再激活；只有 3 条（本轮新沉淀）在窗口内。

## 策略 A vs 策略 B

| 维度 | 策略 A（现状，1 秒窗口） | 策略 B（`--replay-rounds 10`） |
|---|---|---|
| 实现 | sleep 只回放本轮新沉淀 | sleep 前把最近 10 轮沉淀的规则 last_access 刷成 now → 全进窗口 |
| 每轮回放量 | 3~4 条 | **30 条**（最近 10 轮沉淀的全部规则） |
| 旧教训再激活 | 永不 | **周期性（每轮）** |
| access_count 分布 | 只有 2/3 两档 | **2~10 分层积累**（旧教训被反复强化） |
| 活性规则（≥3 次） | 59 条（基线） | 75 条（9 轮后） |
| 均分 | 5.38（轮 190-209，20 轮） | 6.93（轮 214-219，6 轮） |
| 回放开销 | 无 | 纯内存操作，无 LLM 调用，可忽略 |

## 实现要点

- `sync_ft_memory_to_store(store, mems, replay_rounds=N)`：取最近 N 轮沉淀的规则（按 last_access 排序取前 3N 条，每轮约沉淀 3 条），把它们的 `last_access` 刷成 now → 进回放窗口。**按轮数而非秒数**：不受休息时长（60-120s vs 300-900s）影响，语义稳定。
- 进程内单例 `_REPLAY_ROUNDS`，`--replay-rounds` 启动参数（默认 0 = 现状；建议 10）。
- 回放不改 last_access（memagent 防记忆不朽的设计），所以规则会随轮次推移自然滑出窗口——不会永久霸占窗口。

## 诚实边界

- **均分对比不能当因果**：策略 A 段（轮 190-209）恰逢 LLM 服务抖动期（大量 0~2 分），策略 B 段（轮 214-219）服务已恢复。6.93 vs 5.38 的差异主因可能是时间混杂，而非回放窗口。**能确认的机制事实**：旧教训被周期性再激活（access_count 分层积累），且均分没有恶化证据。
- 样本：策略 B 仅 6 轮，需继续积累（evolution_report 的 Δ 铁律遵守对比会自动跟踪）。
- 潜在风险：回放量放大（3→30 条/轮）会让 access_count 普遍快速上涨——但 `freeze_importance=0.8` 保护 importance 不变，注入窗口不依赖 access_count，无实际副作用。

- **正向信号出现了**：总对照 Δ−0.1 → +1.8；同领域 6 领域里 5 个提升、无一持平（异步编程 +6.5 最陡）。回放再激活与规则被遵守之间存在初步正向关联，与「铁律只是背景知识 vs 被反复回放后成为硬约束」的假设一致。

- **下一步观察点**：活性领域覆盖已达 34/40——再过 20 轮后「无活性领域」将趋近于零，总对照会失去意义；届时改用同领域 Δ 追踪（已有 6 领域基线，继续积累 B 段样本）。

## 附 2：同领域配对检验——排除时间混杂的干净评估（追加于 2026-08-15 21:05）

### 方法

上节的总对照（活性 vs 无活性）有结构缺陷：无活性领域多是低练习冷门领域（基线本来就低），且活性领域覆盖 34/40 后对照组近消失。本节改用**同领域配对**：同一领域在策略 A 段与策略 B 段各取**最近一次有效分**（排除截断轮、失败轮、≤0.5 分抖动轮——重试成功且有分的不算失败）对比，消除领域难度差异；再叠加符号检验 / 配对 t 检验评估显著性。

### 关键混杂控制：B 段服务抖动率反而更高

| 段 | 空回复/异常次数 | 每轮率 |
|---|---|---|
| A（190-209，20 轮） | 8 | **0.40/轮** |
| B（214-256，43 轮） | 30 | **0.70/轮** |

此前「策略 B 段恰逢 LLM 服务恢复期」的假设**不成立**——B 段空回复率反而高出 75%。方向上，若存在服务混杂，它偏向**压低** B 段分数而非抬高。因此 B 段在更抖动的环境下仍略高于 A 段，说明同领域配对观察到的正向 Δ 不太可能由服务混杂解释（最多被低估）。

### 补充证据：B 段内部铁律遵守随时间

B 段内有效轮（非截断、>0.5 分）铁律遵守均值：前半 7.14 → 后半 8.00（+0.86）。按 10 轮分桶：214-223:7.14 → 224-233:7.75 → 234-243:8.40 → 244-253:7.17（回落，n=6）——中段上升、后段回落，方向与「回放再激活积累到中段起效」一致，但样本仍小。

### 结论（修正上节）

- **方向**：同领域配对 8 领域 5 升 1 平 2 降，Δ+1.16；结合 B 段抖动率更高这一反向混杂，策略 B 扩窗的真实效果更可能为「小幅正向」，而非此前担心的「时间混杂伪信号」。
- **强度**：符号检验 p=0.289、t=1.66——**统计上仍不显著**。n=8 的配对样本不足以下因果结论，只能定性为「弱正向信号 + 机制事实确凿」。
- **机制事实（不受统计限制）**：回放量 3→30 条/轮、活性规则 56→156 条、覆盖 16→34 领域、access_count 2~19 全谱分层——扩窗确实让旧教训被周期性再激活。
- **下一步**：继续积累 B 段配对样本（每多一轮重跑一次配对检验，n 到 15+ 再下结论）；PDFCreator(−0.5) 与 其他类型(−2.2) 两个反例可单独排查（是否规则未覆盖该领域新题）。
