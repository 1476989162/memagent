# 活性×Δ 负相关的结构性原因研究：偏相关分离混杂（2026-08-15）

## 问题

`track_coder_trend` 关联表早期曾观察到「活性规则数 × Δ均分」负相关（一度到 -0.55）。假说：**活性规则多的领域练得久，首练发生在早期无铁律时代（基数低），Δ 显得负——「练习时长」混杂了「回放活性」**。本次用偏相关把两个变量分离，判断负相关是否真实。

## 方法

从日志直接解析每轮（**排除截断轮、失败轮、≤0.5 抖动轮**），每领域收集 7 个变量：

- 回放活性：active（活性规则数 ≥3）
- 练习时长：n_rounds（有效练习轮数）、first_r（首练轮号）
- 首练基数：first_s（首练分数）
- 其他：avg_acc（平均回放）、rules（规则总数）、delta（Δ均分 = 最近分 − 首练分）

零阶 Spearman + 一阶偏相关 `r_xy.z = (r_xy − r_xz·r_yz) / √((1−r_xz²)(1−r_yz²))`。

## 结果（17 个有效领域）

### 零阶相关

| 相关对 | r | 含义 |
|---|---|---|
| r(活性, Δ) | **+0.001** | **原始负相关已消失**（此前 -0.55 是含截断轮/单轮抖动的假象） |
| r(活性, 练习轮数) | **+0.669** | **混杂确实存在**：活性多的领域练得久 |
| r(练习轮数, Δ) | +0.069 | 但时长本身与 Δ 无关 |
| r(活性, 首练轮号) | +0.151 | 活性与「练得早」弱正相关（非负） |
| r(首练分, Δ) | **−0.645** | **首练基数效应强**：首练越高 Δ 越负（天花板效应） |
| r(首练分, 活性) | +0.091 | 首练高分领域活性略多（弱） |
| r(活性, avg_acc) | +0.491 | 活性与回放深度正相关（自洽） |

### 一阶偏相关（控制混杂后）

| 控制变量 | r(活性, Δ\|·) | 解读 |
|---|---|---|
| 练习轮数 | −0.061 | 控制时长后仍无相关 |
| 首练轮号 | −0.037 | 控制早期性后仍无相关 |
| 首练分 | +0.078 | 控制基数后仍无相关 |
| avg_acc | −0.257 | 活性与深度剥离后无 |
| 规则总数 | +0.006 | 无 |

### 二阶偏相关（同时控制两个）

- 控制练习轮数+首练分：−0.031
- 控制首练轮+首练分：+0.026

**所有偏相关都落在 ±0.1 内。**

## 结论

1. **「活性×Δ 负相关」是假象，不是结构性混杂的产物——原始相关本身就不存在**。干净口径（排除截断/失败/抖动轮、首练取有效轮）下 r(活性,Δ)=+0.001。此前 -0.55/+0.258 的波动来自数据污染：merge_cycles 不标截断轮（把 1.2/1.0 分的截断轮算进首练/最近）、单轮抖动（1.0~4.4）未被过滤。
2. **混杂（活性∝练习时长, r=+0.669）真实存在**，但它**不产生 Δ 负相关**——因为练习时长本身与 Δ 无关（r=+0.069）。假说的因果链断了：练得久 → 活性多 ✓，但练得久 → Δ 负 ✗。
3. **Δ 的真正决定因素是首练基数**（r(首练分,Δ)=−0.645）：首练高分领域 Δ 必然趋负（天花板效应），首练低分领域 Δ 必正（回归均值）——这是**统计必然**，与回放机制无关。
4. **回放活性对 Δ 无独立影响**（所有偏相关 ±0.1 内）——与 `replay_window_experiment` 附 2 的结论一致：扩窗的机制事实确凿（回放量/活性规则数/分层积累），但对分数走势无因果证据。

## 实现

- `track_coder_trend.partial_spearman(xs, ys, zs)`——一阶偏 Spearman（秩变换）。
- `track_coder_trend.domain_confound_analysis(log_text, mems, mode)`——从日志解析（含截断标记）→ 领域变量聚合 → 相关/偏相关 dict。
- `track_coder_trend.print_confound_block(res)`——报告板块，三态判定：原始不显著 / 控制后归零（结构性伪影）/ 控制后仍显著（真实效应）。
- `track_coder_trend.py` 每次运行自动输出该板块（附在活性关联表后）。

## 建议

- **评估指标从「Δ均分」转向「最近均分」**：Δ 受首练基数支配（天花板效应），最近均分才是领域当前真实水位。关联表两列都保留，但结论以最近均分为准。
- **活性×Δ 相关不再作为回放效果指标**：改用「活性领域 vs 无活性领域的铁律遵守 Δ」（evolution_report）与「同领域配对 Δ」（附 2），两者都不受首练基数影响。
- 下次重跑 `track_coder_trend.py` 会自动带上偏相关板块，持续跟踪（样本 17 → 更多领域后偏相关稳定性可复查）。

## 附：活性×Δ 相关时间切片（追加于 2026-08-15 21:30）

### 目的

把单点的「活性×Δ 相关」变成时间序列，观察相关性随回放扩窗（轮 ~214 上线 replay-rounds 10）是否从负转正/由弱转强。

### 方法

每 20 轮一个窗口（`--ts-window` 可调），窗口内每领域取该时段有效分（排除截断/失败/≤0.5 抖动轮）：`w_mean`（该时段均分）× 当前活性做 Spearman（主指标），`w_delta`（该时段首尾 Δ）仅在 ≥2 轮领域上算（辅助）。

### 结果（20 轮窗口）

| 窗口 | 领域 | Δ领域 | r(活性,均分) | r(活性,Δ) |
|---|---|---|---|---|
| 145-164 | 11 | 0 | +0.625 | — |
| 185-204 | 11 | 0 | +0.516 | — |
| 205-224 | 12 | 1 | +0.364 | — |
| 225-244 | 11 | 3 | +0.264 | −0.625 |
| 245-264 | 11 | 1 | +0.030 | — |

扩窗(轮214)前 r(活性,均分) 均值 **+0.570 → 后 +0.147**（Δ−0.424）。

50 轮窗口（样本更足）：145-194:+0.355 → 195-244:+0.488（含 10 个 Δ 领域, r_delta=−0.291）→ 245-294:+0.030。

### 关键结论

1. **从未转正，也从未为负——活性×均分相关全程为正但持续衰减**（+0.625 → +0.030）。不存在「扩窗前负、扩窗后正」的转折。
2. **衰减机制是活性方差收缩而非效应消失**：扩窗 + 冷门保底让几乎所有领域都有活性规则（34/40 领域），领域间活性差异缩小 → 相关被稀释。这与「对照组消失」是同一现象的两种表现。
3. **窗口内 Δ 样本长期不足**（20 轮内领域几乎不重复），r_delta 多数无意义——活性×Δ 的可靠评估仍需跨窗口的同领域配对（见 `replay_window_experiment` 附 2）。
4. **方法论限制（重要）**：活性是当前快照回填历史窗口，早期窗口领域规则后来被回放 → 高估早期活性。趋势可比（相对变化有意义），绝对量不可信。
