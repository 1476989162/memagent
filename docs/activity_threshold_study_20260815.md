# 活性规则判定阈值研究：固定 ≥3 的膨胀与领域内相对排名方案（2026-08-15）

## 问题

`--replay-rounds 10` 扩窗后，最近 10 轮沉淀的规则每轮被回放 +1，**活跃簇的 access_count 随时间普遍涨到 10~19**。固定阈值「活性 = access_count ≥ 3」面临两个问题：

1. **区分度退化**：活跃簇从 3-6 涨到 12+ 后，≥3 与 ≥8、≥12 选出的是同一批规则——阈值从「回放深度」退化成了「是否被回放过」的布尔量。
2. **对照组消失**：无活性领域（无 ≥3 规则）= 策略 B 后从未被回放的领域（实测 11 个，最近被抽轮 115~224）。冷门保底机制会保证每个领域都被抽到 → **无活性领域随时间趋近于零 → 「活性 vs 无活性」Δ 对比本身有保质期**（此问题比阈值更根本，改阈值不解决）。

## 实测现状（轮 256）

- 1359 条 skill，分布 `{2: 1203, 3: 38, 4: 1, ..., 13: 34, 19: 3}`——**88.5% 停在 2**（沉睡，last_access 过旧永不 touch），活跃簇 3~19。
- ≥3 活性 156 条（11.5%）· 覆盖 34 领域；无活性 11 领域（DataTable/HttpClient/JSON相关/Table/分级数据/生成图表等）。
- 模拟：每条规则被 touch 后停留窗口 ~10 轮，最终全部涨到 ~12——**固定阈值在稳态下饱和**（100 轮后 100% 规则 ≥3）。

## 方案对比

| 方案 | 膨胀后行为 | 结论 |
|---|---|---|
| 固定 ≥3（现状） | 活跃簇全涨到 12+ 后，≥3 选全部活跃规则，无深度区分 | ❌ 会饱和 |
| **全局相对排名**（top 25%） | **88.5% 沉睡池 @2 把阈值压到 2 → 100% 全算活性** | ❌ 彻底失效（双峰分布下不可用） |
| **领域内相对排名**（每领域 top 30%，且 >2） | 无论活跃簇涨到 12 还是 20，领域内 top 30% 始终保持相对区分 | ✅ 对膨胀免疫 |

**关键设计点**：活性是「该领域规则被回放的程度」，必须在**领域内部**比较——不能用全局排名（被沉睡池淹没）。`>2` 下限保留「沉睡 vs 活跃」的布尔区分，`top 30%` 提供「活跃内部深度」的相对区分。

## 实现

- `track_coder_trend.active_rule_ids(mems, mode, pct)`——活性规则判定（返回记忆 id 集合），mode=`fix3`（现状）或 `rel`（领域内 top 30%）。
- `domain_activity_stats` / `activity_correlation` 透传 mode；`track_coder_trend.py --active-mode rel`。
- `evolution_report.py` 的 `replay_stats` / `replay_block` / `coder_section` 透传 mode；`--active-mode rel` 时报告标注判定方式。
- 记忆无 `id` 字段时回退 content 作标识（测试数据兼容）。

## 真实数据验证（轮 256，两种模式对比）

| 指标 | fix3 | rel |
|---|---|---|
| 活性规则数 | 156 | 156（当前未膨胀，两者等价） |
| 覆盖领域 | 34 | 34 |
| WordCreator 活性 | 12 | 9（top30% 裁掉刚过 3 的） |
| 条形码 活性 | 11 | 8 |
| Spearman(活性, Δ均分) | +0.258 | +0.257 |
| 铁律遵守 Δ | +1.8 | +1.8 |

**当前两种模式等价**——切换不改变现有结论，`rel` 是为膨胀准备的免疫方案。

## 结论与建议

1. **现在不急于切换**：当前活跃簇仍在 3~19 区间，≥3 未饱和，两种模式输出一致。保持 fix3 为默认，报告可读性好。
2. **膨胀前哨**：当活跃簇最小值 >3（比如半数领域 active ≥ 3 的规则全部 ≥6）时，切换 `--active-mode rel`。切换是**无损**的（对未膨胀数据等价）。
3. **更根本的问题是对照组消失**：无活性领域（11 个）会随冷门保底逐步被回放激活。当无活性领域 <5 时，「活性 vs 无活性」Δ 对比失去意义——届时改用**同领域配对 Δ**（见 `docs/replay_window_experiment_20260815.md` 附 2，已实现 8 领域配对基线）。
4. **avg_acc 是免疫指标**：领域平均回放次数不受阈值影响，`track_coder_trend` 关联表里一直有这一列，可作持续追踪的补充。
